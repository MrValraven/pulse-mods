# Changelog

One section per release. Each release is tagged `<mod>-v<version>`.

## 2026-11-14

- pulse-ports 0.1.0: first publish, holds a command that would start a dev server on a port you keep for your own testing (3000 and your package.json ports) and offers a free one.
- pulse-progress 0.5.0: says why a run stopped, remembers the panel view, Undo after clearing finished runs, active time, a shared price table, and /pulse mods to check for mod updates.
- pulse-cache-tax 2.5.0: a one-hour or five-minute cache setting, keepwarm savings against ping spend, held messages that come back to the prompt box, and hotkeys on the held card.
- pulse-reflect 3.6.0: a visible paused state, Undo for save and discard, a /reflect-rules pane, near-duplicate checks against CLAUDE.md, and failures that name their cause.
- pulse-filetree 0.7.0: an Outside this folder group, faded rows for deleted files, subagent marks, new keys, and git and search failures that name their cause.
- pulse-blast-radius 0.3.0: shows the whole command, holds many more risky forms, runs commands that would discard nothing, and keeps a log of decisions.
- pulse-filetree 0.6.0: Lucide icons in the desktop app, tinted in each type's colour, and the whole pane in the monospaced face.
- pulse-progress 0.4.0: monospace type throughout, with semibold mono titles in place of Fraunces italic.
- pulse-cache-tax 2.4.0: monospace type on the warmth meter and the held-message card.
- pulse-reflect 3.5.0: the learned-rule card in monospace, rule text at 14 px.
- pulse-blast-radius 0.2.0: the desktop band and pane draw their text in the monospaced face.

## 2026-10-13

- pulse-blast-radius 0.1.0: first publish, holds risky Bash commands and shows what they would change before Proceed or Cancel.
- pulse-filetree 0.4.0: coloured file-type badges (TS, JS, {}) and coloured folders like VS Code, faded git-ignored rows, a brighter guide for the folder you are in, folders that unfold and fold smoothly, and hover drawn by the app.
- pulse-progress 0.3.1: the band above the prompt stops jumping back to an older count each second, and its dithered squares twinkle on smoothly through every redraw.
- pulse-cache-tax 2.2.2: plugin.json links the upstream repository.
- pulse-reflect 3.4.0: one card per learned rule, the same four buttons in a fixed order, and the shown rule stays put until you decide.
- pulse-filetree 0.3.0: worded header buttons, colours from the Claude Code theme, aligned date and size columns, and a fading mark on files Claude touched.
- pulse-cache-tax 2.3.0: a warmth meter and a held-message card with Send anyway and Discard message.
